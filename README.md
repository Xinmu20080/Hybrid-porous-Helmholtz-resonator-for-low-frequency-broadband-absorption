The training and testing of the model are built under the Windows 11 operating system. 
The configuration of the computer is AMD Ryzen 5 4600H CPU @ 3.00 GHz and NVIDIA GeForce GTX 1650 Ti.  
It is realized on the Anaconda3 platform with Python version 3.7. 
Keras framework with TensorFlow backend is also used to set up the model. 
The provided code is closely aligned with the implementation used in the paper.
Certain components, such as data normalization, callback functions, and hyperparameter settings, may require users to adjust them accordingly to reproduce the results reported in the paper.
